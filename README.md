# TATA TechPulse – AI & Data Science Assignments

A collection of practical Artificial Intelligence, Machine Learning, Deep Learning, Computer Vision, and Natural Language Processing assignments implemented using Python.

This project contains 8 assignments covering regression, evolutionary algorithms, data preprocessing, predictive maintenance, traffic sign classification, pedestrian detection, and sentiment analysis.
